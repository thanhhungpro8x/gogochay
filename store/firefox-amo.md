# addons.mozilla.org (AMO): submission kit (GoGoChay 1.0.0)

Developer Hub: https://addons.mozilla.org/developers/. Free.

## 1. Packages
```bash
npm ci && npm test && npm run verify
npm run lint:firefox        # Mozilla's linter: must say "errors 0"
                            # → dist/gogochay-firefox.zip  (upload this)
npm run package:source      # → dist/gogochay-source.zip   (upload when asked for source code)
```
**"Do you need to submit source code?" → Yes.** `extension/data/cosmetic.js` and `extension/rules/*.json` are generated from public filter lists by `scripts/build-lists.mjs`, and AMO requires the source of machine-generated code.

Distribution: **On this site** (listed). Compatibility: tick **Firefox** and **Firefox for Android**.

## 3. Notes to reviewer (paste as is)
```
GoGoChay is an ad blocker with a "tray" UI and an offline lookalike-domain warning.

No remote code and no network requests (CSP connect-src 'self'; scripts/verify.mjs enforces it in CI).
data_collection_permissions: none.

Generated files: extension/rules/*.json (declarativeNetRequest rules) and extension/data/cosmetic.js (CSS selectors) are generated by scripts/build-lists.mjs from EasyList, Liste FR and ABPVN at the commits pinned in lists.config.json.
To rebuild (Ubuntu, Node 22):
  npm ci
  node scripts/build-lists.mjs     # downloads the pinned lists from raw.githubusercontent.com
  node scripts/build-firefox.mjs   # → dist/firefox (same as the uploaded package)
CI rebuilds these files on every push and fails if they differ from the repository.

The linter's "coin miner" warning comes from rules/liste_fr.json: it contains rules that BLOCK coin-mining scripts (their URLs appear in the filter list). No mining code is present.
The "unsupported API" warnings (sidePanel, getMatchedRules, setExtensionActionOptions) are Chrome-only calls guarded by feature checks.

Content script on all http/https pages: hides ads, lists hidden elements in the tray, lets the user hide leftover elements, and checks the page hostname for lookalike characters. It sends nothing anywhere.

To test the address warning: the logic is in extension/domain-check.js with unit tests in test/domain-check.test.mjs (npm test). In the browser, map a lookalike host to a local page (e.g. "127.0.0.1 xn--pypal-4ve.com" in /etc/hosts, then serve any page on it): a red bar appears at the top.
Source: https://github.com/thanhhungpro8x/gogochay
```
